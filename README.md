# MySQL Notes

Structured Query Language (SQL) notes designed for the undergraduate level, using GitBook.

📖 **Access the full documentation here:**\
[🔗 MySQL Notes GitBook](https://umranyaman.gitbook.io/mysql_notes/)

***

#### 🗂 Contents

* **Data Types in MySQL**: Numeric, string, and date/time data types.
* **CRUD Operations**: `CREATE`, `READ`, `UPDATE`, and `DELETE`
* **SQL Commands (1-4)**: Step-by-step SQL syntax and practical use cases.
* **Advanced Usage (1 & 2)**: Explore performance optimization and indexing.
* **Aggregate Functions**: Understand `SUM()`, `AVG()`, `COUNT()`, etc.
* **AS - UNION**: Aliasing and combining result sets.
* **Users & Privileges**: Manage user roles and access control.
* **Procedures & Testing**: Stored procedures and debugging techniques.
